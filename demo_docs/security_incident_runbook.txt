Security and Access Control Runbook

All privileged SSH keys must rotate automatically every 90 days.

Multi-factor authentication using hardware FIDO2 tokens is mandatory for production Kubernetes access and administrative logins.

Any unauthorized API key leak must be revoked within 10 minutes and reported to the Chief Security Officer within 4 hours.

Remote employees must connect to the corporate VPN before accessing internal databases or production dashboards.

Security incidents must be recorded in the incident management system with an owner, severity, timeline, and remediation plan.
